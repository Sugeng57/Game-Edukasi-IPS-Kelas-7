Integrasi Real-Time Google Spreadsheet

Hubungkan game kuis ini dengan Google Spreadsheet Anda secara gratis tanpa API key rumit.

Jika dikosongkan, game tetap menyimpan rekap nilai di memori browser dan dapat di-download dalam format .CSV kapan saja.

Cara Membuat Link Google Spreadsheet Real-time (Hanya 2 Menit):

  1. Buka Google Sheets Baru di akun Google Anda.
  2. Klik menu **Ekstensi (Extensions)** → **Apps Script**.
  3. Hapus seluruh kode yang ada, lalu **Copy-Paste kode di bawah ini**:
function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = JSON.parse(e.postData.contents);
  
  // Jika sheet masih kosong, buat Header
  if (sheet.getLastRow() === 0) {
    sheet.appendRow(["Tanggal & Waktu", "Nama Peserta", "Kelas", "No. Absen", "Skor Total", "Benar", "Salah", "Mode", "Waktu Pengerjaan"]);
  }
  
  // Tambahkan baris data nilai siswa secara real-time
  sheet.appendRow([
    data.timestamp || new Date().toLocaleString("id-ID"),
    data.name,
    data.class,
    data.no,
    data.score,
    data.correct,
    data.wrong,
    data.mode,
    data.timeSpent
  ]);
  
  return ContentService.createTextOutput(JSON.stringify({"result": "success"}))
    .setMimeType(ContentService.MimeType.JSON);
}

Rangkuman Ringkas Tema 01

Kehidupan Sosial dan Kondisi Lingkungan Sekitar (IPS Kelas 7)

1. Lokasi Absolut vs Relatif

• Lokasi Absolut: Letak tetap berdasarkan sistem koordinat lintang & bujur. Indonesia: 6°LU-11°LS dan 95°BT-141°BT.

• Lokasi Relatif: Letak yang berubah-ubah sesuai kondisi sekitarnya (contoh: harga tanah naik di Penajam Paser Utara setelah penetapan IKN).

2. Konektivitas Antarruang (Ullman)

• Regional Complementarity: Saling melengkapi karena perbedaan hasil sumber daya (contoh: Brebes komoditas Bawang, Wonosobo komoditas Kentang).

• Intervening Opportunity: Kesempatan berintervensi yang melemahkan interaksi dua wilayah karena adanya wilayah ketiga pengganti.

3. Kondisi Geologis & Bencana

• Indonesia dilalui 2 jalur pegunungan: Sirkum Pasifik dan Sirkum Mediterania.

• Diapit 3 lempeng tektonik utama: Eurasia, Indo-Australia, dan Pasifik.

• Berdampak positif (tanah subur, material bangunan, mineral) dan negatif (rawan gempa, gunung meletus, tsunami hingga 900 km/jam).

4. Kegiatan Ekonomi

• Produksi: Menambah manfaat barang. Membutuhkan 4 faktor: Alam, Tenaga Kerja, Modal, dan Keahlian/Entrepreneurship.

• Distribusi: Langsung, Semilangsung (lewat toko resmi milik produsen), dan Tidak Langsung (lewat distributor/agen).
